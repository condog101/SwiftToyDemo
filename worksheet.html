Learning objectives

  1. Explain what a constant is and why programmers name their values.
  2. Recognise some Swift data types: Float, Int, Bool, arrays and ranges.
  3. Use the edit → compile → run cycle to change a real 3D app.
  4. Read code you didn't write and predict what changing it will do.

Starter: 1 = C, 2 = A, 3 = B, 4 = E, 5 = D

Q1. The shape gets flicked/knocked into the air (an impulse is applied), with a bit of random sideways movement.

Q2. The shape follows the pointer — you carry it around; when released it falls under gravity again.

Q3. Falling slows as gravity approaches 0 (shapes drift/float); past 0 gravity points upwards, so shapes fall up and pile against the ceiling.

A: everything falls and bounces in slow motion (Moon gravity ≈ 1/6 of Earth's). B: ten shapes rain down per press. C: each bounce is bigger than the last — chaos. (Real bounces lose energy to heat/sound; gaining energy would break conservation of energy.) D: far bigger shapes; only a few fit in the cube.

Q4. mass is a Float (decimal number); metallicShapes is a Bool (true/false).

Q5. It's a range: every new shape gets a random size between the two numbers, so shapes vary.

Q6. Only spheres would spawn — a ball pit.
